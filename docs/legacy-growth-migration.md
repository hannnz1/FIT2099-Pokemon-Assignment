日期：2026-10-03。V3 Demo 完成后的成长整合增量；本批不代表阶段1全部完成。

## 完成功能与规则

原地图旧式木守宫、水跃鱼收藏现在可以在成长研究室点击“迁移为 Lv.5”。这是 Demo 自定义迁移规则：旧数据没有等级、经验、技能信息，因此首次设为 Lv.5，经验设为该等级起点，配备该等级可自动学习的初始技能及初始 PP。个体 captureId 和物种保留，HP=最大成长HP×旧HP/100 向下取整，存活个体最低1HP，不自动休息或补满血。木守宫 Lv.5 最大HP19，水跃鱼20。旧存档只在玩家明确返回培养时转换，读取存档不会自动修改旧收藏。

已成长伙伴沿用原有完整档案，不重新设等级或补满PP；之后可带回原地图、召唤及再次返回培养。必须先收回已部署伙伴、取消原地图未结束委托，回到研究室，且成长队伍未满。迁移和普通返回共用所有权记录：先原子提交收藏/成长归属，再提交成长房间；源提交失败保留旧演员和旧存档，目的提交失败重启可依据持久化归属恢复，不复制个体。

## 运行与操作

解压 pokemon-legacy-migration-agent-runtime.zip，双击启动游戏.cmd。打开 http://127.0.0.1:8088/quest/，捕捉野生木守宫／水跃鱼后点击存入收藏。收回已部署伙伴并取消未结束的委托，打开 http://127.0.0.1:8088/growth/，在研究室点击“迁移为 Lv.5”。已有真实旧收藏可直接使用此入口，无需重新捕捉。后续点击“带回原地图”再“返回培养”应保留成长档案。

运行包不含密钥、个人存档、Cookie。可沿用本机OpenAI环境配置；迁移本身不依赖AI。启用原持久化目录即可读取兼容旧收藏格式。
