# V2 第一阶段完成：顺序野外委托（2026-10-02）

支持按顺序执行2–3个不同野生目标。例：“先捕捉一只野生木守宫，然后击败一只野生火稚鸡。不花金币，只在任务区域活动，在第45回合前完成。”

在原地图输入委托，检查确认内容列出的完整顺序和全程限制，再点击“确认并开始”。解析不改变世界；确认通过才开启探索。AI依次执行，前端显示当前阶段、各步骤结果并切换地图目标。所有目标实际完成才显示整体完成。已捕捉个体需玩家选择目标后点击“收入收藏”。

目标为现有木守宫、水跃鱼、火稚鸡。火稚鸡不可捕捉；重复目标、超过3步、树果混合、收藏管理或未知物种组合拒绝。禁止主动战斗与任一击败步骤冲突时拒绝。四类限制共享于整个计划；所有目标的区域在确认前校验。AI和暂停后的手动攻击/捕捉均不能跳到未来目标或改变当前目标操作。

进度以原生目标状态推导，避免单独保存游标与世界不一致。中间阶段暂停/文件或PG重启恢复当前目标，已完成步骤不重做。未确认重启仍等待确认；最后完成后可收藏捕获个体，重启保持整体成功。取消、重置、超时、HP保护和模型预算沿用V1。V1单目标解析、树果委托及旧存档继续兼容；V1运行包已保留，勿使用V1旧程序加载新增复合委托存档。
