# 先选目标，再选互动

附近互动以 Java availableActions 为准，按 targetId 列出角色或脚下物品。按钮显示名称与坐标，同种精灵仍是独立目标。未选择目标时不展示角色互动方式；选择后仅展示该目标的合法动作。地图上的附近角色可直接点击选择，并显示黄色选中框。

目标选择是纯展示操作，不提交动作、不推进回合。请求或动画期间锁定选择；目标被捕获、移除或失去可用互动时清空选择，不自动选中其他角色。点击不可互动的地图角色也清空原选择并提示靠近。无目标的引擎连续动作仍保留独立入口。

精灵互动、博士对话、商人交易和物品拾取都走两步流程；物品丢弃继续保留在背包中。新增浏览器回归覆盖未选中时无动作、切换目标不会推进回合、动作隔离和捕获后清理。

验证：前端 7 项通过；TypeScript/Vite 构建通过；真实 JAR 浏览器 11 项通过（约 1 分钟）。桌面选中效果与手机无横向溢出检查通过。Java 规则未修改。
