## 执行决策与代价

1. 原聊天没有绑定 Git 工作区，原生 worktree 工具不可用；使用独立本地 clone 和 `feat/java-web-demo` 分支。原路径及未提交 client 保留。代价：后续需在交付的开发副本继续，尚未合并回原项目。
2. 计划是阶段式规格且环境为 Windows，按 PowerShell 维护执行账本，代替技能中的 Bash 账本脚本。代价：阶段记录由实现者维护。
3. 本版素材全部用程序绘制占位，不引入授权尚未确认的图片；后续按 manifest 替换。代价：画面精细程度低于参考项目，玩法不受影响。
4. 事件契约按规格补齐，没有接受简化协议。代价：前端改用 message 与数值 amount；尚无需要迁移的外部客户。
5. 公网发布保留 NOT RUN，等待用户指定平台/域名/凭据；本地 JAR 和 Docker 已验收。代价：当前可玩地址只在本机有效。
6. 独立审查保持只读，不启动测试进程；所有测试由实现者实际运行并保存结果。代价：测试执行证据只有一名执行者，审查提供独立代码判断。
7. 保留开发分支，交付可运行包和源码；没有自动合并原目录、推送或公开发布。代价：整合回原目录是后续选择。
