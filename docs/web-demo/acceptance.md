## 失败记录与处理

- 开发前回归测试缺少 GameSession / 只读 HP；实现后通过。
- JVM 在 Windows 沙箱访问依赖 jar 的路径解析受限，使用经审查的本地构建执行权限；不改游戏逻辑绕过测试。
- HTTP 旧测试客户端自动剥离 Origin，改为 JDK HttpClient 后按真实请求验证。
- 发布资源脚本误把 URL 对象传给 path.join，修正为文件系统路径。
- 生命周期 REMOVE 重复两次：已复现并去重；新测试通过。
- 独立审查发现地图不符仍能键盘行动、帮助偏好写反、事件契约缺字段；全部修复并有失败转通过证据。同步读取输入锁也一并修复。
- 一次负载运行因“从发送时刻计间隔”在队列延迟下形成突发，返回预期 429；改成每次响应后等待后，最终 2,000 动作通过。
- 一次容器多标签页 E2E 在隐藏页等待动画而超时；Phaser 在页面隐藏时暂停循环。测试改为像真实用户一样切到操作标签页，并将断言等待设为 12 秒（产品网络超时为 8 秒）。随后系统 Chrome 的整组复跑仍有超时；改用 Playwright 1.58.2 配套 Chromium 145 后，最终 6/6 全部通过，默认配置与 CI 同步固定。未更改回合规则规避测试。
