# V2 后续扩展：AI 指挥收藏伙伴（2026-10-02）

已完成玩家选择收藏个体、确认后自动召唤、AI控制其真实移动/捕捉/攻击、顺序野外委托、低HP暂停，以及文件和PostgreSQL恢复。原文档协作V2仍全部保留；本次属于它之后的扩展，不将尚未开发的混合任务等宣称完成。

## 玩法与边界

1. 在原地图“AI 出战伙伴”中选择默认水跃鱼或自己收藏的木守宫/水跃鱼个体。选择器显示真实HP和个体编号，多个同物种不会混用。
2. 输入野外目标，例如“捕捉一只野生水跃鱼，不花金币，不主动战斗”。确认页显示所选个体、生命值和目标；解析不放出伙伴、不推进世界回合。选择冻结于确认和执行期间。
3. 点击确认后，服务器寻找合法且符合区域限制的相邻格自动召唤该个体；已放出的同一伙伴直接使用。其他伙伴占着召唤名额则明确拒绝，请先收回它。停止跟随后AI指挥收藏伙伴，默认水跃鱼仍留在原位置，并遵循既有世界生命值保护。
4. 单目标捕捉/击败与2–3个不同野生目标的顺序任务均可使用收藏伙伴。AI观察和工具以该真实Actor的位置和HP计算，目标仍是野生个体，任务NPC和收藏个体不能作为野生目标攻击。
5. 禁止花金币、禁止主动战斗、允许区域、截止回合、审批及原有工具限制继续保留。区域校验覆盖召唤点、伙伴当前位置和目标；火稚鸡不可捕捉。
6. 无法安全承担下一次反击时自动暂停并显示休整提示，不继续反复攻击。可暂停后收回；让默认水跃鱼靠近博士，选择收藏个体免费休整，再召唤同一个体并继续。继续会重新绑定该个体并停止跟随；不能拿另一只冒充原任务伙伴。每轮仍有既有模型、步骤、时间和恢复预算，生命值/随机命中会影响战斗结果。
7. 任务完成后捕获物留在实际精灵球里，点击“收入收藏”保存。自动召唤不花金币、不推进回合；移动和战斗按实际世界规则计回合。新一轮自动收回伙伴并保留收藏。
8. 树果任务和玩家协作模式使用默认委托水跃鱼。选择收藏伙伴提交树果任务会明确拒绝，不悄悄换执行者。此版本没有AI自动挑选最优个体、收回/休整的自主计划，也不接受自然语言收藏管理命令；通过选择器明确授权出战个体。

## 保存与隔离

AI出战个体ID在解析确认和执行阶段保存。未确认重启仍等待确认、未完成重启暂停等待玩家继续、完成重启保持真实结果。动态Actor绑定在召唤恢复后取实际对象；行动记录归属该个体。外部玩家的收藏ID或不存在的个体拒绝；错误绑定拒绝恢复。召唤写入失败冻结AI，恢复后依据真实提交结果继续确认。旧任务无新字段时默认水跃鱼；建议独立解压新运行包，勿让旧程序加载新增收藏AI任务存档。

## 运行

解压pokemon-owned-agent-runtime.zip，Java8或更高版本，双击“启动游戏.cmd”，打开http://127.0.0.1:8088/quest/。沿用本机OPENAI_API_KEY，默认gpt-6-luna，运行包不含密钥或验收存档。先捕捉并收入收藏，再开始新一轮，从AI出战伙伴选择器选择该个体。
