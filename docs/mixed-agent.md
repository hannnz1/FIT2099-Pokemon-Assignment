# V2 后续扩展：混合委托（2026-10-02）

已完成树果交付与捕捉/击败组成的顺序混合委托。原文档协作 V2、AI 收藏伙伴、Phaser 原地图与训练场继续保留。本次是已有 V2 之后的扩展。

## 玩法

在原地图输入：先收集3个树果送给博士，再捕捉一只野生木守宫，最后击败野生火稚鸡。全程不花金币，只在任务区域活动，在第60回合前完成。

确认页显示完整顺序、全程限制、截止回合和执行伙伴。确认后 AI 逐阶段执行，树果实际交付3个只完成树果阶段；所有阶段的原生目标达成后才报告整条委托完成。前端显示各阶段的当前/待执行/完成状态。

支持2–3阶段，恰好一次3树果交付，其余是不同野生目标的捕捉或击败；树果可放在第一、中间或最后。捕捉木守宫/水跃鱼无需先削弱，火稚鸡仍不可捕捉。禁止主动战斗与击败要求冲突时拒绝任务。金币、区域、绝对截止回合约束全程有效，没有为下一阶段重置回合或资源。

选择收藏伙伴时，树果阶段由默认水跃鱼执行，野外阶段自动使用选定的实际收藏个体。伙伴自动召唤、停止跟随；服务器按阶段绑定真实 Actor，行动记录区分执行个体，保留现有所有权、低HP暂停和休整规则。树果库存与原生交付计算不被虚构。

服务器禁止跳过当前阶段或使用上一阶段的修改工具，暂停后的手动拾取/交付和野外攻击/捕捉也遵守阶段。observe 等只读操作不消耗世界回合。游走 NPC 占住树果格时，导航先实际靠近，然后消耗真实回合等待它离开；不会搬动 NPC、远程拾取或凭空补树果。等待受同一截止回合、生命值和步骤预算约束，随机战斗/阻塞仍可能导致任务失败。

## 存档与范围

文件和 PostgreSQL 保存阶段定义、实际交付与野生目标状态及所选伙伴。未完成任务重启暂停等玩家继续，已完成任务保留完成结果；完成树果后恢复不会再交付一遍。旧任务存档仍可读取。新增 stagedBerry 记录区分树果阶段完成与整条任务完成；旧程序无法保证读取新增混合存档，建议独立解压新包。

混合委托限单人原地图 AI 流程。现有玩家协作模式继续使用共享3树果任务；尚未扩展为玩家和 AI 同时推进混合阶段。自然语言自动收藏管理、自动休整、成长/技能系统、更多地图、多 Agent（V3）、评测沙盒（V4）、完整战斗（V5）、多人联网与正式部署仍未开发。

## 运行

解压pokemon-mixed-agent-runtime.zip，Java8或更高版本，双击启动游戏.cmd，打开http://127.0.0.1:8088/quest/。默认读取本机OPENAI_API_KEY，模型gpt-6-luna；包不含密钥、.env或验收存档。收藏伙伴需先捕捉收入收藏，然后新一轮在AI出战伙伴中选定。
