# 原地图召唤与收回宝可梦

更新：2026-10-01。本文记录召唤阶段；后续已支持自动跟随，最新功能与验收见 [跟随说明](pokemon-follow.md)。

解压最新运行包，双击“启动游戏.cmd”，需要 Java 8 或更新版本。在训练场向东移动一格，捕捉木守宫，点击“带回原地图”，再返回原地图。选择收藏个体和方向，点击“召唤宝可梦”；点击“收回宝可梦”将同一个个体放回精灵球。

一次放出一只，放在水跃鱼相邻且可以进入的空格。地图显示“我的木守宫”，与原地图提供线索的木守宫 NPC 分开。召唤使用真实游戏 Actor 和地图占位，玩家及寻路不能穿过；收回才释放格子。实际生命值保持不变。召唤、收回不推进回合、不花金币。新一轮委托自动收回，保留收藏。AI 正在解析、等待确认、执行或等待审批时不能管理收藏；先结束相应阶段。旧标签页、错误玩家及过期操作不能改动。

当前放出的宝可梦驻留原位，没有自动跟随或战斗；水跃鱼仍执行委托。替换伙伴、原地图野生战斗和更多可携带物种是后续扩展。

## 存档与恢复

收藏检查点同时保存个体所有权与可选部署位置，是单一权威记录。先保存部署/收回记录，再调整真实库存和地图，避免复制精灵球或留下幽灵占位。文件与 PostgreSQL 均可恢复；旧收藏存档没有部署字段时默认在精灵球中。

保存失败或提交结果不确定会冻结操作；使用“恢复存档”重新读取并核对收藏和世界。恢复位置被占用或越界时保持冻结，不会删除个体或悄悄换位置。请保留浏览器 Cookie、保存目录与服务端口，并备份存档；不要用旧版程序继续写新版部署存档。
