# 地图素材、边界与委托失败恢复修复报告

日期：2026-10-03。对应用户提出的三项 UI 问题，代码更新至原项目，本次不扩展 V5。

## 本轮修改

- 21 种宝可梦、42 张人物肖像/地图形象已存在并核对。新增10项地点/人物/物品映射：研究室、商店、林间树、博士、商人、玩家、果园、树果、恢复点、区域出口。建筑复用现有地图真实切片，人物使用现有角色帧与角色配色，四项图标为原创 SVG。来源和切片坐标见 world-art-audit.md；没有将来源不同的整套美术混用。
- 场景按实际 Java 地图尺寸、碰撞与出口绘制：金色实线为真实地图边界，蓝色虚线为视口裁切、外侧仍有地图，斜线格为不可通行地形，金色门标明出口目的地。边界内收5px，避免画布裁切或键盘焦点框遮住线。训练场保持真实9×3格。
- 三页加入明显的失败恢复卡片。树果委托/训练失败可开始新一轮，明确告知地图重置、已收入收藏保留；成长失败保留队伍、经验和进度，并提供返研究室、恢复HP/PP和重新培养入口。
- 修正到期任务 manualAllowed 与后端规则不一致的实际错误；到期后不再展示貌似可用但动作被拒绝的移动按钮。待确认请求只重试原请求；重复轮询不把重试按钮意外禁用。断线、模型不可用、存档异常各显示对应处理入口。
- 素材通过真实SVG文件装载，解决Phaser不支持本地data URI导致一直加载的问题。
- 连续操作达到房间256条历史上限时，明确提示停止任务、重启本地服务后重新连接；不绕过操作预算。持久存储读取原存档，内存模式提示可能丢失进度。此限制仍保留，不宣称无限轮次。
