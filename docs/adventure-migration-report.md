# 冒险手册与现有存档转入连续冒险修复

2026-10-03。

问题：按钮禁用却没有说明原因；连续冒险只允许回合0、研究室、最多一名伙伴开启，导致已有进度无法使用。

修复：每个冒险手册按钮下显示具体原因，包含回研究室、先开启连续冒险、剩余野生目标数量、前一区域未完成、图鉴收集数量、条件达成回研究室领取、已领取，以及网络、操作处理中、AI培养、存档恢复等阻塞状态。原因同时作为按钮辅助说明，手机390px下自动单列且无横向溢出。

已有自由探索存档回研究室后，可以点击“开始连续冒险（保留伙伴）”。保留所有成长队伍个体、等级、经验、技能、PP、HP、图鉴收藏、已领奖记录和当前回合；重新生成调查遭遇并将探索轮次归一，从森林调查开始，河岸及山道按完成顺序解锁。界面提前说明保留及重新生成范围，读档不会自行转换。已开启的连续冒险不会被重复重置。正在执行或暂停的未完成AI培养必须先取消再开启，以免旧培养路线指向新锁定地图。

验证：新增3项Java迁移测试和3项前端原因测试，先确认旧代码失败再修复。完整Java533/533通过，包括21项实际PostgreSQL数据库测试；前端145/145通过。真实文件旧档浏览器验收：沼跃鱼Lv17从森林返回研究室后入口可点击，转换后HP28/53、撞击PP7、距下一级678EXP保持，图鉴收藏2种保持，森林剩余3目标、河岸和山道锁定的原因可见；重载后连续冒险及Lv17仍保留。手机390px宽度无横向溢出，控制台无错误或警告。本轮使用独立测试存档和离线AI配置，没有改动用户正在玩的服务和存档，没有调用收费AI。

本包包含此前地图入口、粉色辅助层、跨地图AI目标显示、自动进化及建筑素材修复。

使用：完整解压运行包后双击“启动游戏.cmd”。升级旧目录时，先关闭原游戏服务并备份，将本包pokemon-phaser-game.jar替换原目录同名文件，保留原saves和API配置，再重启服务并刷新页面。回研究室，取消未完成的培养委托，然后点击“开始连续冒险（保留伙伴）”。只刷新页面不能更新旧服务。
