# 树果任务浏览器版

2026-09-30。本阶段将真实 Java 树果场景、自然语言任务确认和购买审批接到独立中文页面。
默认继续使用玩家选定的低价模型 `gpt-6-luna`；Gemini 可通过环境变量选择。
这不是原游戏所有地图、战斗与存档都已浏览器化的声明。当前总体进度见 [开发进度](development-progress.md)。

## 运行

下载本轮提供的 `pokemon-agent-web.jar`，在已配置 `OPENAI_API_KEY` 的本机终端运行：

```sh
java -jar pokemon-agent-web.jar
```

打开 **http://127.0.0.1:8088**。输入树果任务，点击“理解我的委托”，检查目标和约束，
再点击“确认并开始”。页面显示真实水跃鱼位置、背包、金币、交付数量和行动记录。
出现购买请求时可批准、拒绝或取消；不批准不会购买。可以暂停、继续、取消和开始新一轮。
模型不一定选择商店路线；从林间获取第三个树果也是合法完成方式。

| 环境变量 | 默认值 | 含义 |
| --- | --- | --- |
| OPENAI_API_KEY | 必填 | 只存于服务端环境；页面和日志不输出 |
| OPENAI_MODEL | gpt-6-luna | 可覆盖模型，无自动切换昂贵模型 |
| OPENAI_TIMEOUT_MS | 15000 | 单次模型请求时限，1–60000 毫秒 |
| LLM_PROVIDER | openai | 指定 gemini 时使用 GEMINI_API_KEY / GEMINI_MODEL / GEMINI_TIMEOUT_MS |
| AGENT_PORT | 8088 | 本机端口，仍只监听 127.0.0.1 |

无密钥也能启动页面，但不能启动模型任务。端口被占用时可配置其他端口。
使用 URL 中的 127.0.0.1；Host 和 Origin 必须与实际端口相符。
重启服务清空内存场景，页面会重新建立会话；不会恢复上一轮资产或重放旧命令。

源码构建环境可使用原有 Maven 配置：

```sh
mvn clean verify
java -cp target/classes game.agent.web.AgentWebServer
```

Maven 已配置打包五个页面资源，包含 NPC 交流展示模块。既有 `game.Application` 控制台入口继续独立运行。
此机器 Maven/JDK 测试依赖读取仍有 AccessDeniedException，因此本轮没有宣称 Maven 全流程通过。
本轮实际使用 ECJ + JUnit 全套测试、`javac --release 8` 编译和独立 JAR 打包验证。

## 实现与限制

- `AgentWebServer` 使用 JDK HttpServer，无新增 Java 生产依赖。最多 8 个 Cookie 会话，每会话一个独立真实引擎场景。
  Cookie 按实际端口隔离，不同端口的本机服务不会互相覆盖会话。
- 场景创建、操作、快照和模型结果提交在同一世界线程执行；两个后台模型线程只处理不可变上下文。
  HTTP 和模型工作池有界，不在世界线程等网络请求。
- 页面与 API 同源，500 毫秒轮询；HttpOnly / SameSite=Strict Cookie、CSRF、Origin、Host 与静态资源白名单检查。
  POST JSON 最大 16 KiB，任务描述最多 1000 字符，未知字段/参数类型拒绝，不开放任意工具执行。
- 命令绑定 requestId、taskId、expectedRevision；重复载荷返回原结果，不重复执行。
  不同载荷不能复用 ID，旧任务拒绝；暂停/取消允许同任务旧视图，便于立即停止。
- 每房间保存最多 256 个幂等结果，满后拒绝普通命令；取消仍可用。
  每会话每分钟最多 60 次普通 POST。每房间整个生命周期最多解析 3 次、恢复 3 次；重置场景不清这两个调用预算。
  单任务最多 30 次模型决策、单移动最多 12 步、连续失败 5 次；累计活跃执行时限 120 秒，等待玩家与暂停不计入。
- 审批绑定服务端 Cookie 身份，只接收 proposalId。精确数量、总价、权限、库存、距离、TTL 和单次使用规则仍由 Java 校验。
  批准令牌只在服务端和模型工具参数间使用，浏览器快照、审批回复与记录都不包含令牌。
- 前端命令回复只确认接收，不能更新金币/物品。断线禁用操作，重试复用同一个请求载荷。
  新任务和新会话不会被迟到的旧快照覆盖；会话失效后清理旧待重试请求并重新连接。
- UI 只显示实际动作码对应的简短说明，不显示或伪造模型隐藏推理。内存轨迹最多 64 条。

场景包含果园 2 个树果、林间 1 个树果、商店、博士与真实地图移动。
商店金币经济仍独立于原游戏 Candy 经济。任务截止是 60 个场景行动回合，尚未接入原世界 NIGHT。
等待模型、购买确认和暂停不推进此场景回合；原地图 NPC、昼夜伤害与传统手动控制仍待联调。
该服务用于本机演示，不是联网部署或多人共享世界。

新版 NPC 对话、测试与运行包见 [NPC 记忆交流阶段](npc-memory-dialogue-v1.md)。下面保留浏览器初次接入时的历史验收记录。

## 浏览器初次接入验收

- 全部 Java 测试 120/120，包括新增 9 项房间/真实 HTTP 测试。
- 全部客户端测试 24/24，包括新增 6 项树果客户端测试。
- 全部生产代码通过 Java 8 API 编译。
- 真实 HTTP 离线集成测试：确认后实际拾取与交付；不同 Cookie 不能读其他房间；
  CSRF/Origin/Host/大小/未知字段拒绝；审批等待停回合；重复批准不重复购买，币数从 5 变为 4，背包增加 1。
  这些测试明确使用假模型 HTTP 响应、真实 Java 游戏规则，没有向提供方收费调用。
- 使用本机真实 OpenAI Key，在打包后的浏览器版完成一次 Luna 任务：
  解析 NO_SPENDING 和 NO_ACTIVE_BATTLE，确认前位置 (0,1)、交付 0；确认后实际交付 3，金币保持 5，位置 (7,1)，状态 COMPLETED。
  此次真实模型自主选择免费路线，没有脚本替代，也没有声称真实模型触发购买审批。
- 只读审查发现并修复服务重启重连问题与输入上限不一致，补充回归测试。
- 最终包在浏览器验证了断线时停用按钮、服务重启后不刷新自动恢复操作；最终页面与服务已启动供本机体验。
