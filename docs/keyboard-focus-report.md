# 点击操作按钮后方向键失灵修复

2026-10-03。

根因：成长地图键盘事件要求焦点位于地图内，并将BUTTON、A视作禁止键盘移动。触控移动或其他按钮点击后焦点停留在按钮或页面背景，所以方向键不再向后端发送移动操作。其他Phaser地图有同类焦点范围限制。

修复：成长地图、委托地图和训练地图使用统一键盘监听。普通按钮、链接及页面背景获得焦点后，方向键和WASD继续控制角色，无需再次点地图。INPUT、SELECT、TEXTAREA及可编辑内容保留原生编辑行为；Ctrl、Alt、Meta、Shift快捷键不触发移动；AI控制、忙碌、网络断开、存档异常仍使用原操作权限。长按自动重复不重复提交移动，同时阻止方向键滚动页面。监听销毁时移除，避免重复绑定。成长页面提示同步说明。

先在旧包浏览器复现：触控向西到(8,9)，焦点BUTTON，按ArrowUp回合4位置保持不变。修复后真实文件存档：按钮焦点下ArrowUp到(8,8)；触控向东到(9,8)、同按钮焦点ArrowDown到(9,9)；点击选择目标后ArrowUp到(9,8)；目标等级输入框ArrowUp只改变表单，回合8及(9,8)不变。控制台无错误或警告。
