# Phaser 反馈与首次试玩引导

2026-10-01，本阶段完成原地图和训练场的操作反馈。

- 相同任务的新世界回合才产生反馈；首次装载、重复轮询、旧快照、新一轮不重播。动画只是展示 Java 已确认的坐标、生命值和捕捉状态。
- 单格移动使用180毫秒位置过渡；真实损失生命值显示数值并闪烁。攻击未命中从真实动作记录显示；捕捉与击败分别提示，目标不保留幽灵实体。
- 当前野生目标以白圈标记，下拉框和地图选择共用目标。NPC、野生和收藏伙伴保留独立名称和个体身份。
- 首次试玩步骤随当前世界和收藏状态更新，不记录虚构的历史操作。两场景提供任务锁定、等待操作确认、读档和新一轮提示；禁用按钮提供具体前置条件。
- 遵守系统减少动态效果设置，关闭移动过渡和闪烁，结果文字仍可查看。

验证：客户端58/58，Java260/260（含本机隔离PostgreSQL，无跳过），生产Java8编译成功。浏览器实测移动、未命中及真实反击、捕捉、带回收藏、切换原地图、探索、召唤、目标切换、重启恢复及新一轮。浏览器错误/警告记录为空。目标受伤和击败反馈另由状态差分测试覆盖，本轮没有重新调用真实OpenAI API；此前实网验收仍作为历史证据。

本轮是界面反馈增强，未增加原地图自然语言捕捉/战斗委托。目前原地图AI仍执行树果委托；自然语言捕捉/击败在独立训练场支持。多人、多Agent和任意复合目标仍是后续扩展。移动过渡使用现有静态素材，不是新增四方向行走精灵帧。
