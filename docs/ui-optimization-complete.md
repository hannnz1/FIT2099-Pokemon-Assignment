## 使用

解压 pokemon-ui-complete-agent-runtime.zip，在 Java 8 或更新版本环境下双击“启动游戏.cmd”。沿用本机环境变量配置，不在运行包中保存 API 密钥。

- 伙伴冒险：http://127.0.0.1:8088/growth/
- AI 委托：http://127.0.0.1:8088/quest/
- 战斗训练：http://127.0.0.1:8088/training/
- 评测中心：http://127.0.0.1:8088/evaluation/

运行包、源码包、独立 JAR、校验和及页面截图均另存为 ui-complete 版本，保留旧 V4/第一批 UI 包。包内不含测试存档、会话凭据或 API 密钥。
