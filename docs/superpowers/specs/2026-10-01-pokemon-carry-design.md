# 训练场宝可梦带回原地图

玩家持续授权继续开发；本阶段选取尚未完成的跨场景携带，沿用 Java 8、真实引擎、现有 OpenAI 默认设置和存档。

## 设计

玩家在训练场捕捉后点击“带回原地图”。只接受服务器真实训练场捕捉的木守宫，并保留实际 HP。两边的回合和树果/金币不变。原地图显示玩家的实际精灵球收藏背包，本阶段不提供召唤、战斗或替换 AI 伙伴。

引入玩家收藏 `collection:<owner>`，独立于可重置的两边场景，是跨场景所有权的唯一权威。每个训练局持久保存 arenaId，捕捉身份为 arenaId；同局当前只有一个可捕捉目标。收藏保存接收身份和实际物种/HP，最多20个。该单检查点原子提交后才能移出训练场真实球库存。训练场已转移的目标保持捕捉完成历史，显示 TRANSFERRED，不能重复捕捉。

若收藏提交失败或结果未知，不移动来源球，返回存储错误并冻结来源；重新恢复时加载收藏并按接收记录对账。即使收藏成功而来源存档失败，接收记录也在重启和恢复前移除旧来源库存，防止双份资产。新训练局获得新 arenaId；两个场景重置均不清除收藏。老存档没有 arenaId 时使用旧场景内容的确定性身份，首次修改后持久化。

HTTP 仍要求 Origin/CSRF、当前训练场控制权、任务身份、修订号和唯一请求。AI 行动中或解析/确认中不能转移；暂停/结束后可转移。收藏只允许当前会话读取。用单独 Player 的真实 Pokeball 库存承载原地图玩家收藏，不占水跃鱼的树果容量。

## 验收

捕捉→转移→原地图实际背包；重复点击不增加；训练重置后可捕捉新的个体；原地图重置保留；相同Cookie重启；来源和收藏写入失败、提交结果未知；跨玩家/错误目标/旧修订/旧标签页拒绝。Java8编译、全Java和客户端套件、打包浏览器及重启实测。
