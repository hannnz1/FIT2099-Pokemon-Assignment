日期：2026-10-03。研究室、森林、浅溪河岸、赤岩山道现在共用 Java 原生移动、技能结算与持久化。阶段2按下述 Demo 范围完成，下一阶段是新增物种与成长内容。

## 新功能

- 地图连接为研究室 ↔ 苔叶森林 ↔ 浅溪河岸 ↔ 赤岩山道。前往任一区域时，Java 先选择连接门，再逐格寻路；经过中间地图继续 IN_PROGRESS，到目标地图才完成导航。方向键、WASD和区域按钮均遵守原生碰撞。
- 新地图各20×14格、每格64像素。河流有水域、双格宽木桥、左右岸、森林与山地连接门；水域禁止直接行走，木桥可通行。山地有岩石边界、两段崖壁和通行缺口。默认门全部开放；区域解锁与冒险任务属于阶段4。
- 河流恢复点(4,8)、山地恢复点(4,9)，森林保留(9,8)。必须站在营地或位于研究室才能恢复全队 HP/PP。倒下伙伴仍可走回营地；恢复不增加经验或刷新遭遇。
- 每张野外地图独立保存三个遭遇及探索轮次。森林用木守宫/水跃鱼/火稚鸡；河流用水跃鱼/水跃鱼/木守宫；山地用火稚鸡/火稚鸡/水跃鱼。首位目标等级为 min(38, max(区域最低等级, 伙伴等级-1+区域偏移))，其余两位依次加1，最高39。森林最低5/偏移0，河流最低6/偏移1，山地最低8/偏移2。这些是 Demo 自定义遭遇规则。
- 目标的个体ID、HP、PP、状态、已捕捉/击败结果在跨地图往返和重启后保留。攻击与接近仅允许当前区域目标。研究室的“开始下一轮探索”只重置选定区域，并要求该区域本轮全部结束；其他区域进度保持。每区域最多200轮。
- 带出伙伴保留已有区域进度，最后一位伙伴带出后也不刷新野生目标。已捕捉个体带回原地图时，遭遇标为 TRANSFERRED，返回培养时重新关联同一个体；队伍所有权继续沿用已有跨场景协议。
- AI 培养面板增加区域选择，目标区域随委托保存。AI工具只能前往固定培养区域或研究室，连接图中间地图由Java导航处理；暂停期间手动换地图后，恢复委托仍保留原目标区域。AI依据真实观测使用技能、营地恢复、返回研究室准备新一轮。
- 成长世界存档升级为 schemaVersion 2，兼容读取原schemaVersion 1森林存档，不重新生成原森林个体。新增分区轮次和遭遇区域校验，非法区域、碰撞位置、跨区域战斗指向及缺损遭遇组被拒绝。成长房间保留原协议，targetRegion字段可兼容旧检查点。新格式应继续用新版读取。
