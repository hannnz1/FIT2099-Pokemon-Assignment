## V3 第一批已实现

新增Java MultiAgentFoundation及可运行的MultiAgentFoundationDemo。注册Mudkip/Torchic/Professor/Merchant四类角色，采用轮询选择工作，每个角色独立预算（1–32次派发），一次只允许一个未完成租约。预算在派发时扣减，失败也占额度，不属于token或费用统计。权限白名单禁止博士/商人移动、攻击和改写背包；调度器只授权，最终世界动作仍须由调用者在Java世界线程校验提交。

消息由可信服务端确认发送者与观察来源；每条有不可变ID、发送者、接收者、观察回合、发送回合、到期回合和坐标。只向对应接收者提供消息与记忆；相同请求去重，改写同ID被拒绝，最多64条、有效期最多10回合。接收记忆使用现有NpcMemory/MemoryService，来源固定NPC_MESSAGE，消息不是实时世界事实，必须重新观察。过期信息保留为历史，发送前不能查到。

工作结果携带世界revision；迟到结果被拒绝，同一租约不能执行两次。检查点保存轮询位置、已消耗预算和消息收据；恢复不会重放在途租约。文件和真实PG往返通过。新增16项Java测试覆盖公平性、预算、权限、迟到与重复、来源与隔离、过期与未来信息、容量、快照防改写、损坏存档及恢复。

独立JAR基础演示实测：依次派发mudkip、torchic、professor、merchant；Torchic向博士发送一条示例历史消息；商人不可读取；文件保存恢复一致，博士看到过期标记。演示使用显式原型观察数据，没有调用模型或读取/改变主地图。V3基础代码尚未接入主地图NPC或前端，不会让现有角色自动调用API。

## 运行

解压pokemon-v2-complete-v3-start-runtime.zip，双击“启动游戏.cmd”，进入http://127.0.0.1:8088/quest/，即可体验已完成的V2及此前单人/成长功能。使用本机OPENAI_API_KEY，沿用当前默认模型gpt-6-luna。包内无密钥、会话Cookie和个人存档。

双击“启动V3基础验证.cmd”可运行独立基础演示，在终端输出JSON验收结果，示例存档位于data/v3-foundation。它是研发验证入口，不是完整多Agent游戏。也可运行：

java -cp pokemon-phaser-game.jar game.agent.demo.MultiAgentFoundationDemo data/v3-foundation
