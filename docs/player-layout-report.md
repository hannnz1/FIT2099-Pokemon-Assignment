# 玩家操作页面布局升级

2026-10-04。本次升级伙伴冒险 /growth/ 页面。

顶部显示地图名称、探索昼夜、回合和真实存档状态，提供设置和帮助。主体保留 Phaser 地图，右侧显示当前伙伴、等级、HP、经验、目标、技能 PP 和任务状态。底部提供队伍、背包、图鉴、AI 培养委托四个弹窗入口。队伍面板保留休整、技能学习、奖励和伙伴转移；区域导航、冒险手册及行动记录使用独立面板。

背包展示实际收在球中的队伍伙伴。成长模式没有独立消耗品库存；采集物品仍属于委托地图。昼夜按成长回合每 5 回合切换，只用于时段显示，不改变 HP。复用现有宝可梦图像、像素地图和绿色配色。

弹窗打开时阻止键盘移动，关闭或 Escape 后重新聚焦地图。手机采用纵向布局和固定底部操作栏。离线、存档失败、操作待确认、内存存档和已同步分别显示，避免错误提示保存成功。

验证：前端 161/161 测试通过；Java 8 兼容生产 JAR 构建成功。独立服务器 8196 浏览器验证了队伍、背包、图鉴筛选、AI 面板、设置开关，弹窗期间方向键不移动地图，关闭后方向键恢复，触控后键盘可以继续移动；目标选择、接近、吸取攻击及捕捉失败反馈正确更新 HP、PP 和回合。1280×720 桌面操作栏可见，390×844 窄屏没有横向溢出。控制台无警告和错误。

本次未调用真实 AI 模型；测试服务器没有配置模型。未重跑全部 Java/数据库测试。用户服务和存档未改动。生产包资源逐字校验、Java 8 字节码和 ZIP CRC 验证通过。

更新：先关闭旧游戏服务并备份 saves，用新包 pokemon-phaser-game.jar 替换旧文件，保留 saves 和 API 配置，重启后在伙伴冒险页按 Ctrl+F5。也可以完整解压运行包后启动“启动游戏.cmd”；不要在 ZIP 内直接启动。
