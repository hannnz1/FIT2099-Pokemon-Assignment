# 伙伴升级与自动进化修复

2026-10-03。

根因：原来升级只结算经验，进化被设计成研究室手动操作，因此水跃鱼Lv.17仍显示初始形态；界面展示的Lv.16只是预告。按照本次要求改为伙伴冒险成长队伍自动进化。

拥有的伙伴通过战斗或奖励达到物种的进化等级，会自动改变实际species，名称、能力、类型、头像、地图精灵、图鉴与进化预告使用更新后的服务器数据。三只初始伙伴Lv.16进入第二形态，Lv.36进入最终形态；其他物种使用其已配置的各自门槛。无额外进化指令或额外回合，AI委托继续使用原个体ID和原培养目标。四个已装备技能不会被强行替换。

旧的超过门槛但未进化成长存档在校验通过后自动补齐进化；超过两段门槛可补到最终形态。原个体ID、经验和已装备PP保留，HP按新上限比例换算，倒下者仍为0HP。旧伙伴从委托地图返回成长队伍及高等级野生伙伴捕捉进入成长队伍，也遵守同一规则。原始存档文件没有批量修改；正常游戏保存会写入进化后的状态。

验证：先运行4项新增测试均出现预期断言失败，再修复；涵盖Lv15/16/17/36、御三家两段链、奖励、真实战斗、旧档、导入、重复读档和倒下状态。完整Java530/530通过，含21项实际PostgreSQL测试；前端142/142通过。浏览器以真实文件旧档水跃鱼Lv17读入，显示沼跃鱼Lv17，头像marshtomp.png及地图精灵一致，HP28/53、撞击PP7保留；移动到回合2后保存再重新加载仍为沼跃鱼。无控制台错误或警告。本轮未调用收费AI模型。

本包包含此前地图粉色辅助层默认隐藏、入口自动切换、木牌小径、跨地图委托显示修复及建筑去绿。

安装：完整解压pokemon-auto-evolution-agent-runtime.zip，再双击启动游戏.cmd。已运行的旧包请先关闭游戏服务并备份，将本包pokemon-phaser-game.jar替换旧目录同名文件，保留原saves目录及本地API设置。重启服务并刷新页面后，已有Lv.17水跃鱼会自动显示为沼跃鱼，无需删除存档或从Lv.5重练。仅刷新旧服务无法更新后端规则。
