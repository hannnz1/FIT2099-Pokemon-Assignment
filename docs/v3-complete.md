# V3 Multi-Agent World Demo 完成验收（2026-10-03）

按原始开发文档第22节 V3 范围交付：Torchic / Professor / Merchant Agent、Agent-Agent 信息传播、更完整长期记忆、Reflection 和 Daily Planning。水跃鱼沿用真实委托模型循环，三个 NPC 独立思考，Java 世界线程校验并提交动作。当前完成的是有预算、有范围的 V3 Demo，不是无限开放世界。

## 完成功能

1. 四角色协作：火稚鸡提供附近树果线索，博士转述线索并报告进度，商人提供自身报价，水跃鱼执行委托。角色私有观察与收件箱隔离。世界变化使迟到结果失效；支持暂停、取消、模式切换与恢复。
2. 长期记忆：每角色16条变化快照；淘汰快照按事实ID压缩为最多32条记录，保留来源、首次/最后观察回合、次数与最后内容。支持文本/主题检索，近期检索结果和压缩历史均传给模型。角色间隔离、深拷贝与存档校验。它是同一世界内的有界记忆；新一轮重置，不是向量检索或跨世界记忆。
3. Reflection：模型通过 reflect_plan 输出中文反思，必须引用本角色持有的观察证据ID。服务器限制长度和工具权限；内容明确标为模型推断、liveFact=false，不自动变成世界事实。自然语言推断可能不准确，事实和行为以Java校验为准。
4. Daily Planning：60回合为一天，0–19早段、20–39中段、40–59晚段。三段计划文本由真实模型生成；阶段、观察、收件箱或信息分享目标变化会触发重规划。下一动作受角色协作目标与权限约束，执行工具须与保存计划一致。第60回合仍按现有Demo规则结束，不代表已实现无限多日游戏。
5. 信息传播：支持接收者转述已有消息，保留根消息、父消息和角色路径，不能改写正文或延长有效期。拒绝未收到、过期、循环及重复转述。接收者必须现场核实资源。
6. 前端：展示三个角色的中文反思、证据、三阶段计划、当前阶段、下一动作、待重规划标记及记忆数量。原地图、角色像素素材、暂停继续入口保留。
7. 联合任务：玩家和水跃鱼共同交付，NPC提供可追踪的信息。补充当前剩余数量的决策提示，避免已集齐剩余树果后仍按原总数重复搜索；动作继续由模型选择，无脚本代跑。

## 运行及验收步骤

解压 pokemon-v3-complete-agent-runtime.zip，双击启动游戏.cmd，打开 http://127.0.0.1:8088/quest/。沿用本机 OPENAI_API_KEY，默认gpt-6-luna；包内不含密钥、Cookie或个人存档。

新一轮回合0，可先开启玩家协作，再开启多角色协作。等待角色计划和带来源消息出现，提交“我们一起收集3个树果送给博士，不花金币，不主动战斗”。确认委托后点击继续角色；玩家可同时移动、采集和交付。通过共享账本确认双方贡献，交付总数3后任务完成。模型解析、购买审批与任务终态会暂停NPC。

每个NPC最多32次派发，失败和轮询跳过计额度；完全无变化时不再派发或调用模型。上限至多96次NPC模型调用，水跃鱼有独立预算；这是调用次数保护，不是货币费用统计。预算耗尽不会自动补充。恢复不会重放在途动作，需手动继续。
