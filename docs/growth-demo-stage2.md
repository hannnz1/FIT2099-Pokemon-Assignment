# 成长 Demo 第二批：Lv.40 与最终进化（2026-10-02）

本批在研究室/森林与独立成长队伍基础上，补完三只初始伙伴的两次等级进化。Java 决定战斗、经验、HP/PP 与进化结果，Phaser 显示实际状态。原混合委托和协作 V2 保留。

## 运行与旧存档

解压 pokemon-growth2-agent-runtime.zip，使用 Java 8 或更高版本，双击启动游戏.cmd，打开 http://127.0.0.1:8088/growth/。AI 读取本机 OPENAI_API_KEY，默认 gpt-6-luna；包中不含密钥和测试存档。没有密钥仍可手动玩。

同一端口、浏览器身份及存档目录可恢复第一批成长存档。升级前备份 saves；新版本可读取旧成长存档，但 Lv.20 以上的新存档不能交给第一批旧程序读取。成长队伍仍独立于原委托收藏。

## 新玩法与数值

| 初始伙伴 | 第一次进化 | 最终进化 |
|---|---|---|
| 木守宫 | Lv.16 森林蜥蜴 | Lv.36 蜥蜴王 |
| 水跃鱼 | Lv.16 沼跃鱼 | Lv.36 巨沼怪 |
| 火稚鸡 | Lv.16 力壮鸡 | Lv.36 火焰鸡 |

等级上限由20提升到40；累计经验 Lv.36 为40,007，Lv.40为56,660。三条链共9形态，种族值沿用第三世代参考，固定IV15、EV0、中性数值。森林新一轮遭遇随当前伙伴等级增长，最高Lv.39，既有未完成遭遇保持原状态。经验奖励仍为 floor(产出×野生等级/7)×3。

进化须回研究室、达到当前形态对应等级且伙伴未倒下，需玩家主动确认。进化保留个体ID、累计经验、装备技能及剩余PP，并按HP比例调整生命值。越过等级后仍可逐次进化，不会直接跳过中间形态。首次进化里程碑仅奖励一次，不会因新增最终形态失效或重复领取。

新接入12技能，总计27：刺耳声、超级吸取、高速移动、摔打、叶刃、泼沙、健美、劈开、火焰拳、火焰踢、猛撞、浊流。仍最多装备四个，学习/替换在研究室主动操作。

- 森林蜥蜴/蜥蜴王 Lv.29 解锁叶刃，Lv.35解锁高速移动。
- 力壮鸡/火焰鸡 Lv.28解锁健美；火焰鸡最终进化后可学习火焰拳、Lv.36火焰踢。力壮鸡Lv.39劈开与火焰鸡Lv.42劈开的差异保留；本批上限40，已装备的前形态技能可保留。
- 沼跃鱼Lv.31猛撞、Lv.37浊流；巨沼怪Lv.31猛撞、Lv.39浊流。晚进化保留已装备技能，但未装备技能按当前形态的学习表解锁。
- 状态技能支持降防两级、提升速度两级、提升攻击/防御一级、降低命中。猛撞产生实际伤害的1/4反伤；浊流命中后有30%概率降低命中。吸取回复、灼伤、PP和能力等级仍实际结算。
- 叶刃、劈开、火焰踢实现1/8高会心及两倍伤害，并忽略不利攻防等级；火焰踢另有10%灼伤。普通技能随机会心、完整异常状态、特性等仍未实现，不能称为完整RSE战斗。

AI 可培养当前个体到Lv.40，通过实际导航、技能战斗、恢复和开启新一轮获取经验。保留每次任务200次决策、100步移动与10分钟活动时间等预算；长跨度培养建议分多次委托。达到目标不会自动进化或替换技能。

最终形态继续复用上一形态的现有Monster Tamer/AxulArt图片，界面名称与数值区分，未新增原版宝可梦图像。整体素材风格保持一致，美术来源见 client/THIRD_PARTY_NOTICES.md。

## 长期存档修复

真实连续培养发现旧版本回执长期累积会超过JSON存档节点限制。本次成长回执保留最新64条，旧存档读取后收缩回执窗口；正常过期请求被版本校验拒绝，重复执行不会额外加经验。仍保留最近64条战斗记录与64条AI步骤。文件写入失败继续冻结操作，允许恢复最后提交状态，不会假报存档成功。
