# 宝可梦形象替换与界面扩展

2026-10-02：已替换木守宫、森林蜥蜴、蜥蜴王，火稚鸡、力壮鸡、火焰鸡，水跃鱼、沼跃鱼、巨沼怪，共9个形态。

伙伴、野生目标、初始选择卡和进化预览使用 PokeAPI sprites 收录的 official-artwork 原始 PNG。地图使用同一套第三世代绿宝石像素图；AI委托、战斗训练及成长页面均已接入。地图图像为静态像素角色，移动由 Phaser 位移实现。

新增三张初始伙伴图片选择卡及下次进化形象、等级预览。保留 Lv.5 初始、Lv.16/36进化、Lv.40上限与已有存档格式。

验收：Java355/355（含真实 PostgreSQL）、前端79/79、Maven成功；18张图片HTTP内容及PNG类型、三个玩法模块路由及Java8字节码核验通过。浏览器检查见验收记录。此前真实OpenAI成长验收记录保留在growth2报告，本批未宣称重新完成AI实网验收。

运行：解压 pokemon-art-agent-runtime.zip，双击启动游戏.cmd，打开 http://127.0.0.1:8088/growth/ 。可切换 AI委托与战斗训练。AI仍从本机环境变量读取密钥，默认模型gpt-6-luna。包内不包含密钥和个人存档。

来源、原始地址、SHA256及上游许可记录在 client/assets/images/pokemon/；素材权利说明在 client/THIRD_PARTY_NOTICES.md。此批使用宝可梦参考素材的本地Demo，开源仓库许可不等于宝可梦图像商业授权。
