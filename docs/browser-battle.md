# 浏览器战斗与捕捉训练场

更新：2026-10-01。此阶段接入独立浏览器训练场，V1 树果委托入口保持可用。后续已完成统一入口及 [捕捉宝可梦带回原地图收藏](pokemon-carry.md)，本页早期验收计数为历史记录。

## 已完成

- 9×3 实际引擎地图、伙伴与目标位置、生命条、捕捉背包。
- 手动四向移动、攻击、敌方实际反击、真实精灵球捕捉及行动结果。
- OpenAI 结构化解析“捕捉木守宫，不要主动战斗”“击败火稚鸡”，先展示目标和限制，再由玩家确认执行。
- 服务端可信目标、距离与存活校验；禁止主动战斗约束；捕捉不算击败；拒绝多目标、未知目标和未支持的限制。
- 暂停、继续、取消、重新训练；AI 执行中禁止手动双重控制。迟到解析和模型响应不能恢复已取消的动作。
- 重复请求不重复改变世界；任务与修订号校验；沿用本地 HTTP Origin、CSRF、Cookie 及玩家隔离保护。
- 文件或 PostgreSQL 全场景检查点，训练场使用独立玩家命名空间；未完成任务重启保持暂停，终止任务保留终止状态，模型工作不恢复。
- 存档失败停止动作；显式恢复，包括首次存档失败；120 秒累计执行上限、30 次决策上限、5 次连续失败上限、3 次解析/继续上限。
- 有界行动记录、实际工具参数和结果、模型延迟与用量统计；观察和完成通知不推进世界回合。

## 运行

最新统一运行包提供“启动游戏.cmd”，同一服务可访问 `/quest/` 和 `/training/`；旧阶段运行包仍使用各自的启动文件。本机需 Java 8 或更高，AI 使用现有环境变量 `OPENAI_API_KEY`，默认模型 `gpt-6-luna`。密钥不写入页面、存档或运行包。

从工程运行 `game.agent.web.AgentWebServer`，默认端口 8088。`AGENT_MODE=battle` 仅设置根地址默认场景，两个显式入口均可用。切换规则见 [统一入口说明](unified-entry.md)。

默认文件存档；可继续使用已有 `AGENT_STORAGE=postgres`、`AGENT_DB_URL`、`AGENT_DB_USER` 和 `AGENT_DB_PASSWORD` 配置。训练场不会读取或覆盖树果任务存档。

## 验收

启动已配置 OpenAI 的训练场后可运行：

```powershell
.\scripts\accept-browser-battle.ps1 -BaseUrl http://127.0.0.1:8091
```

脚本创建自己的新浏览器会话，用真实 OpenAI 分别解析和执行捕捉、击败目标，检查实际背包、目标状态和生命值，并输出完整快照与 `report.json`。没有脚本模型回退；失败先保留 NOT_PASSED，避免误用上次通过记录。此前在线验收结果保留在浏览器战斗阶段运行包。最新脚本默认使用 `/api/training`，旧版独立服务需传 `-ApiBase /api/agent`；统一入口运行包仅提供本阶段离线切换验收，没有宣称新增实网调用。

自动测试覆盖真实 HTTP 调用、取消/暂停迟到工作、重复捕捉、实际战斗与完成判定、读档新任务身份、完成/取消多次重启、存档故障恢复、超时越界存档恢复、解析错误/额度耗尽不推进世界。浏览器实测核对生命值、背包、禁止按钮和服务器重启结果。

## 当前边界

沿用原引擎规则：普通球无限；木守宫可直接捕捉；火稚鸡不可捕捉。攻击有随机命中及反击。支持单个训练场目标，不支持任意宝可梦、复合战斗任务或完整原地图战斗模式。战斗解析当前仅接入 OpenAI。

后续仍有多人共享世界、协作贡献与归属、多 Agent 调度、长期规划与记忆反思、公开部署。这些不属于已完成的 V1 或本次训练场交付。
