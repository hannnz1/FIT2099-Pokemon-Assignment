# Gemini 与自然语言任务：Java 接入阶段

2026-09-30。本阶段补齐 Gemini 接口、自然语言任务解析和可运行控制台，兼容 Java 8，
没有新增生产依赖。运行在原引擎的真实地图、角色与 Berry 对象上。
目前没有配置真实 API Key，因此仅完成离线接口与游戏规则验证，未验证真实模型响应、配额或费用。

## 注册与配置

1. 使用 Google 账号登录 [Google AI Studio API Keys](https://aistudio.google.com/apikey)。
2. 接受条款。新用户通常会自动获得默认项目和 API Key；也可在 API Keys 页面创建。
   已有 Cloud 项目的用户可先在 Dashboard → Projects 导入项目，再创建 Key。
3. 在 Windows 搜索“编辑账户的环境变量”，新建用户变量 `GEMINI_API_KEY`，值为密钥。
4. 保存后重新打开终端。若要从 Codex 启动，也需让启动它的进程重新加载环境变量。

密钥不写入源码、命令行参数、浏览器或聊天。官方步骤：
[Using Gemini API keys](https://ai.google.dev/gemini-api/docs/api-key)。

可选环境变量：

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| GEMINI_MODEL | gemini-3.8-flash | 请求的模型 ID |
| GEMINI_TIMEOUT_MS | 15000 | 单次 HTTPS 请求时限，1–60000 毫秒 |

模型默认值依据 2026-09-30 的[官方模型文档](https://ai.google.dev/gemini-api/docs/models)。
账号可用模型和配额以实际 API 返回为准。程序不会自动改模型或重试以增加请求量。

## 运行

交付的独立 JAR：

```sh
java -jar pokemon-gemini-agent.jar
```

标准 Maven 环境也可编译后执行：

```sh
mvn clean verify
java -cp target/classes game.agent.demo.GeminiAgentConsole
```

输入示例：`帮我完成树果任务，不要花金币，也不要主动战斗`。
程序先请求结构化解析，再显示目标与约束。玩家输入 `y` 确认才启动任务。
不支持的目标、区域限制、自定义截止时间或其他条款会被拒绝；模型仍可能理解错误，
因此确认界面是启动前的必要步骤。

地图有 3 个真实树果：果园 2 个，另一地点 1 个。也有商人和博士。
模型可选择免费拾取路线，或向玩家请求具体购买审批。
采购数量、价格和提示由游戏规则计算；玩家选择允许、拒绝或取消。
只有实际向博士交付 3 个树果，游戏才报告完成。

缺少密钥时退出码为 2，解析失败为 3，运行停止/失败为 4，成功为 0。
缺少密钥不会发送网络请求；失败后不改用脚本冒充真实模型成功。

## 已完成的接入

- `LlmGateway` 与 `GeminiGateway`：固定 Google HTTPS generateContent 接口；
  将已注册工具和严格参数约束转换成函数声明。每个请求是一次独立决策。
- 只接受一个已注册工具调用；未知工具、额外参数、非法值、多调用、纯文字、
  安全拦截及不完整响应都会拒绝。模型提供的调用 ID 不参与游戏幂等键生成。
- `NaturalTaskParser`：结构化解析当前可信 questId；支持 `NO_SPENDING`、
  `NO_ACTIVE_BATTLE`。约束经过玩家确认，再应用到任务。当前场景没有攻击工具。
- 可信执行线程读取不可变观察，后台线程只请求模型。结果回到执行线程后，
  再校验任务生命周期、超时、工具参数和游戏条件；迟到结果不能改变世界。
- 连接/读取时限、整体请求计时与断开、响应大小和 UTF-8 校验；解析入口另有等待时限。
  429、认证、超时、不可用、安全拦截等错误转换为有限原因码，日志不输出响应正文或密钥。
- 控制台串行执行真实移动、拾取、审批与交付，并提供单次运行时限。
  等待模型与审批时不推进此确定性场景的 Quest 回合；审批令牌使用独立毫秒有效期。

JSON 编解码器限制大小、层数、令牌数和数值长度，拒绝重复字段、无效 Unicode 与非法数字。
JSON、模型和网络层均为 Java 实现；上游移植来源与许可证继续见 `third_party`。
本阶段 Gemini 适配器为项目新增实现，没有直接复制另一款游戏的完整客户端。
