## 运行

解压 pokemon-v4-complete-agent-runtime.zip，安装 Java 8 或更新版本，双击“启动游戏.cmd”。游戏 http://127.0.0.1:8088/quest/，成长 http://127.0.0.1:8088/growth/，评测 http://127.0.0.1:8088/evaluation/。

真实 AI 沿用本机 OPENAI_API_KEY，默认便宜模型 gpt-6-luna；规则基线不需要密钥。可设置 EVAL_MODELS=gpt-6-luna,gpt-5.4-mini 指定比较模型白名单，最多四个模型。选择场景、Seed、重复次数后加入队列，再查看结果/回放/下载。基线无供应商 usage，因此 Token 显示未知。

## Demo 范围与边界

每批最多 24 案例、每用户最多 8 批，每案例最多 100 决策、128 动作记录，默认 180 秒。仅本机服务，未实现云端多用户运营、批次删除/无限历史或大型调度集群。

共享/竞争评测冻结地形自发变化以实现复现；角色时间、HP、种子化移动、对话和真实工具结算仍运行，正常游戏地形逻辑保持原样。信息转发使用两个角色阶段串行测试现有来源链协议，不等同于新增并行 NPC 系统。V3 已有 NPC 功能保留。

完整 RSE 复刻、商业发布、V5 对战 Agent 均不属于本次 V4 完成标准。
