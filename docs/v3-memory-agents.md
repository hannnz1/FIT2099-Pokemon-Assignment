# V3 第二批：观察历史与重复消息抑制

本批为三个 NPC 增加各自独立的观察历史，最多保留16次变化快照；不变的观察不重复写入。历史、成功观察签名与角色预算一起持久化，旧检查点缺少这些字段仍可恢复。新一轮重置，不提供跨世界长期记忆。容量满时淘汰最旧快照，目前没有语义检索或压缩。

成功行动后，后续观察事实和位置未变化时跳过模型调用与重复发送；失败仍允许下一次重试。跳过仍消耗本轮派发额度，每个NPC最多4次，不自动续费或补预算。

加入有证据ID的规则摘要，以及观察后分享变化事实的固定计划原型。两者明确标记 RULE_BASED，传入角色自己的模型上下文，并显示于网页角色消息与行动记录详情。它们不是模型生成的Reflection或Daily Planning。消息仍是历史观察，需要现场确认。

验收：Java408/408通过，包含15项真实PostgreSQL；前端81/81；Maven BUILD SUCCESS（默认15项PG跳过，已另行全部实测）。Java8 class版本52，网页与34项RPG资源逐字节一致。新增8项测试覆盖变化/不变观察、角色隔离、容量、快照恢复、非法来源/倒退回合、拷贝隔离、成功去重和失败重试。

真实OpenAI gpt-6-luna：HTTP与浏览器分别验收，三个角色各发送1条消息，随后9次未变化观察跳过，无脚本模型回退，金币5、世界回合0。重启后消息、记忆、预算和位置一致；网页地图READY，控制台无警告/错误。空闲委托taskId重建，角色记录未重放。模型在本次选择发送消息；未宣称模型执行了移动或完成联合树果任务。

运行：解压 pokemon-v3-memory-agent-runtime.zip，双击启动游戏.cmd，打开 http://127.0.0.1:8088/quest/，沿用本机 OPENAI_API_KEY。新一轮回合0开启多角色协作，展开角色消息与行动记录查看 cognition。包内无密钥、Cookie和个人存档。
