# Phaser 实时游戏接入（2026-10-01）

当前 Java Demo 的 `/quest/` 和 `/training/` 已采用本地 Phaser 3.60 和仓库现有 Monster Tamer / AxulArt RPG 素材。地图来自真实 Java 地形；角色坐标、目标状态、生命值、回合来自服务器快照。已捕捉、转移、击败的野生实体不再绘制；收藏个体与默认伙伴分别显示。

解压新版 pokemon-phaser-game-runtime.zip，使用 Java8 或更新版本，双击“启动游戏.cmd”，访问 http://127.0.0.1:8088/quest/ 。手动玩法无需模型密钥。AI 沿用本机环境中的 OpenAI 配置，默认 gpt-6-luna。保留 saves 和浏览器会话可恢复进度。

点击地图取得焦点后使用方向键或 WASD 移动当前伙伴；点击野生实体选择目标；攻击、捕捉、收藏、召唤和审批沿用界面按钮。输入框内打字不会移动角色。AI 控制、断线或未知请求期间禁止键盘命令。可展开文字地图查看坐标。画布加载失败保留按钮与文字地图。

采用上游地图的地形片段、灌木、人物、森林战斗背景和三种代用怪物图片；不是官方宝可梦精灵图。页面和运行包保留素材署名。地图按 Java 原始规则重绘，没有把上游参考地图的碰撞或剧情冒充当前游戏状态。

原 client/index.html 的“回声群岛”章节/多人接口仍是另一个前端方案，尚未接入 Java；preview.html 是夹具，reference.html 是上游单机参考。此次完成当前 V1 的 Phaser 展示与操作，不包含该独立章节/多人方案。

验证：Java 260/260（含实际 PostgreSQL），前端 50/50，生产类 Java8 major52。打包浏览器实际验证素材、移动、捕捉、收入收藏、召唤、切换出战、攻击、键盘、输入框隔离、训练捕捉转移与服务重启恢复。HTTP 游戏验收 PASSED；未新增真实模型调用。独立复审通过。当前主机标准 Maven 仍有既有 ZIP 文件访问限制，发布包以 release8 编译和实际运行验证为准。

资源：固定白名单；二进制 MIME 与 PNG 文件正确；Phaser 内部图片支持 data/blob，脚本和接口仍限同源。共享打包脚本 client/tools/pack-agent-resources.mjs 与 Maven 资源清单一致。
