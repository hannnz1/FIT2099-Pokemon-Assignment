# V1 Demo 最终完成说明（2026-10-02）

原始 V1 必需功能和已约定的单人玩法扩展已完成。Java 游戏引擎仍是位置、库存、金币、生命值和任务结果的唯一依据，Phaser 展示实际状态。

## 已完成功能

- 自然语言树果委托：收集3个树果并交给博士；不花金币、不主动战斗、区域限制、截止回合；确认、暂停、继续、取消、购买审批和异常恢复。
- NPC 对话与历史记忆、实际行动记录及模型统计；文件和 PostgreSQL 存档。
- 训练场捕捉木守宫及击败火稚鸡；跨场景收藏、召唤/收回、自动跟随、选择收藏伙伴手动出战、休整和濒危救助。
- 原地图手动探索、捕捉木守宫/水跃鱼、攻击野生目标；捕获个体可收入收藏。
- Phaser 本地素材、目标选择/高亮、移动过渡、实际伤害/未命中/捕捉/击败反馈、操作限制和首次试玩引导。
- 本轮新增原地图 AI 单目标捕捉/击败委托：解析仅生成确认；确认校验通过后开启探索，由水跃鱼移动并执行。目标实际被捕捉/击败才算成功。四类约束由 Java 检查，野外工具不能购买、交付、管理收藏或攻击其他目标。
- 未确认任务重启仍等待确认；已完成任务重启保持成功；最后有效行动到达截止回合仍能正确成功，且计入实际回合。存储失败冻结操作，恢复后核对实际状态。

## 运行

解压最终运行包，使用Java8或更高版本，双击“启动游戏.cmd”。打开 http://127.0.0.1:8088/quest/ ，训练场 /training/。AI沿用本机OPENAI_API_KEY，默认gpt-6-luna；手动玩法无需密钥。存档位于解压目录saves。运行包不包含密钥或验收会话存档。

委托例子：“捕捉一只野生水跃鱼，不花金币，不主动战斗，只在任务区域活动，在第40回合前完成。”“击败野生火稚鸡，不花金币，在第45回合前完成。”
