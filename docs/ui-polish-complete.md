# Pokémon Demo UI 优化 · 第一批完成

日期：2026-10-03。按用户要求暂不开发 V5，工作重心转为已有玩法的界面与交互。V1–V4 Demo 功能保留。

## 本批变化

1. 主冒险页面：统一浅色窗口、深绿标题栏与柔和金色重点；沿用现有像素地图和宝可梦插画，地图居左、伙伴和主要操作居右。新增“现在做什么”，按连接、存档、AI 行动、伙伴倒下、目标距离等实际状态给出下一步提示。野生卡片只展示当前区域。
2. 伙伴展示：统一插画比例、等级徽标、真实 HP 数值与血条、状态、距离下一级所需 EXP。队伍和收藏使用一致卡片；旧式未成长个体保持等级未知，不虚构 Lv.5。带回收藏的成长个体由现有 EXP 曲线正确显示等级。
3. AI 委托：理解、确认、执行、完成四阶段；中文等待/重新规划/暂停/审批/失败反馈。示例按钮只填写任务，由玩家提交和确认，不自动启动。保留暂停、继续、取消和新一轮。真实进度来自游戏快照，无模拟百分比。
4. 信息层次：能力/性格/进化、学习技能、规则、角色消息、详细记录和模型信息收进展开区。能力面板在移动、AI 行动和刷新时保持展开。野外技能仍保留在实际操作区，不藏入规则说明。
5. 导航与窄屏：冒险、AI 委托、战斗训练、评测中心使用统一名称；保留原有安全切换逻辑。训练页使用共享窗口样式。390px 宽度下两类主页面无横向溢出；方向按钮具有文字无障碍标签，保留键盘移动和减少动画偏好。

## 使用

解压 pokemon-ui-polish-agent-runtime.zip，在安装 Java 8 或更新版本的本机双击“启动游戏.cmd”。

- 伙伴冒险：http://127.0.0.1:8088/growth/
- AI 委托：http://127.0.0.1:8088/quest/
- 战斗训练：http://127.0.0.1:8088/training/
- 评测中心：http://127.0.0.1:8088/evaluation/

AI 沿用本机 OPENAI_API_KEY 与默认便宜模型 gpt-6-luna；运行包不含密钥或测试存档。旧版窗口需要刷新才能加载新界面。原项目代码已更新，旧 V4 交付包独立保留。
