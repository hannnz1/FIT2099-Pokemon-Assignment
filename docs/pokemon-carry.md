# 把训练场宝可梦带回原地图

更新：2026-10-01。本文记录携带阶段；后续已完成原地图召唤与收回，最新功能和验收见 [召唤说明](pokemon-summon.md)。

启动最新运行包中的“启动游戏.cmd”，进入 `/training/`。向东移动一格，捕捉木守宫，然后点击“带回原地图”。原地图 `/quest/` 的“我的宝可梦背包”会显示收到的木守宫与实际生命值；训练场背包移出该精灵球，目标显示“已带回原地图”。转移不会消耗金币或推进回合。

AI 正在行动时请先暂停，解析中或等待确认时先确认/取消。操作仍要求当前场景、任务和修订号。重复点击、重试以及重启不会从同一次捕捉领取多个个体；新的训练局可以捕捉新的个体。收藏最多20个，满时来源精灵球保留在训练场。普通球无限及火稚鸡不可捕捉仍沿用原引擎。

收藏属于玩家，使用真实 Player/Pokeball 库存，独立于水跃鱼树果容量。两个场景都能查看，重新训练或新一轮委托不会清空，文件和 PostgreSQL 均支持恢复。保存目录与浏览器 Cookie、端口请保留；不要降级到不识别新转移状态的旧运行包后继续写存档。

接收记录是唯一所有权依据，先原子保存收藏再移出来源库存。存储失败冻结训练场操作；点击“恢复存档”重新读取并核对记录。收藏已提交而来源保存失败时，恢复或重启会移除旧来源库存。若存档确实丢失或损坏，恢复会报错并保持冻结，请保留文件和备份，避免删除收藏检查点。

本阶段支持携带与收藏，没有开放原地图召唤、替换伙伴、野生战斗、任意物种或复合战斗目标。
