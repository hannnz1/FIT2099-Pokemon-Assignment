# 本地 AI 委托修复与验收（2026-10-05）

## 完成的修复

1. 延续交付优先和临时占位等待规则，补充循环保护：同一现场状态反复进入模型决策、采集/交付没有变化时自动暂停。检测在模型决策边界执行，不计正常导航续步；玩家真实位置、库存或交付进度变化会重置检测窗口。
2. 自动暂停在主面板显示实际原因，提供继续、查看行动记录、取消入口；背包和交付进度保留。普通手动暂停保持原行为。
3. 暂停原因写入存档，重启后保留；旧存档可以从最后一条已提交的行动记录恢复原因。继续后清空本轮循环与导航失败窗口，不重放旧模型请求。
4. 修复引擎交付动作绕过连续失败上限的问题。所有交付动作仍接受原工具权限校验，受区域限制的动作不会一直重试。
5. 任务观察导致到期后直接停止，不再误报内部 LOOP_ERROR。
6. 11 级存档写入失败测试：故障后冻结操作，恢复到最后已提交等级和队伍，解除故障后可再次保存。成长页面增加有限存储错误分类（读写、数据库、体积、校验等），不显示私钥、路径或原始异常。原用户报告的 11 级故障根因仍未确认，不能把注入测试当作根因复现。
7. 评测案例记录执行策略版本历史，保留旧存档的 legacy-unversioned 标识；日志和回放区分引擎交付规则与模型动作。
