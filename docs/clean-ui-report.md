# 伙伴冒险界面精简

2026-10-04。适用 /growth/ 页面。

## 改动

压缩顶部与底栏，正常连接时隐藏重复连接行，仅异常或操作待确认时保留连接入口。顶部简洁显示地图名、昼夜和保存状态。

地图容器与 Phaser 画布保持同比例，消除两侧留空，不拉伸像素素材。坐标、回合、视口和边界图例移到“帮助 → 地图边界与探索数据”，出口路牌和地图边界线仍保留在游戏画面。图形地图加载失败时仍在主界面显示错误。

伙伴卡片取消嵌套边框，保留头像、名字、等级、状态和 HP，经验改为细进度条，数值在能力详情中查看。技能卡片只显示名称、属性和 PP；悬停或“ⓘ 技能说明”查看威力、命中等信息。未选有效野生目标时收起技能和捕捉区，靠近后隐藏接近按钮；捕捉后自动回到探索状态。

任务卡片显示简短目标，冒险手册保留详细说明。桌面默认隐藏触控方向键，可在设置开启；手机始终显示方向键和固定底栏。已抵达、技能结算、连接成功、捕捉成功等提示 4 秒后消失；未列入成功提示的错误和重要反馈持续显示。存档与连接异常继续保留恢复面板。

## 验证

前端 162/162 测试通过，新增有效目标显示条件与成功/关键反馈分类测试先失败后通过。JS 语法检查通过。Java 8 兼容生产 JAR、资源逐字匹配、HTTP 静态访问、字节码及 ZIP CRC 校验通过。本次无 Java 业务逻辑改动，复用上一版生产编译结果，未重跑所有 Java/数据库测试，也未调用真实 AI 模型。

独立 8196 测试存档浏览器验证：正常连接时隐藏连接行；未选目标收起技能，选中后恢复技能，接近后接近按钮消失；技能说明和地图边界帮助可访问；弹窗打开时方向键不移动，Escape 后可移动；开启桌面触控后触控和方向键均可继续使用。手机捕捉木守宫成功，队伍数由 1 变 2，技能区收起，成功提示自动消失。控制台无警告或错误。桌面地图容器与画布同比例，1280×720 下底栏可见；390×844 手机无横向溢出，触控与底栏可用。

用户游戏服务和存档未改动。截图来自独立测试存档。

## 更新

关闭旧游戏服务并备份 saves，用本包 pokemon-phaser-game.jar 替换旧 JAR，保留 saves 和 API 配置，重启后在伙伴冒险页面按 Ctrl+F5。也可完整解压运行包后运行启动游戏.cmd；不要直接在 ZIP 中启动。
